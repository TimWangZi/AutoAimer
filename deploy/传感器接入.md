# ICM-426xx 与 SDM20 接入

## 接线

以下编号均为标准 Luckfox Pico 的物理脚号。两个模块统一使用 3.3 V，并与主板共地。

| 模块 | 模块信号 | Pico 物理脚 | RV1103 功能 |
|---|---|---:|---|
| ICM-426xx | SDA | 9 | GPIO1_D2 / I2C3_SDA_M1 |
| ICM-426xx | SCL | 10 | GPIO1_D3 / I2C3_SCL_M1 |
| ICM-426xx | V / G | 36 / 8 | 3V3_OUT / GND |
| SDM20 | TX，模块 3 脚 | 20 | GPIO1_D1 / UART3_RX_M1 |
| SDM20 | RX，模块 4 脚 | 19 | GPIO1_D0 / UART3_TX_M1 |
| SDM20 | VCC，模块 2 脚 | 36 | 3V3_OUT |
| SDM20 | GND，模块 6 脚 | 18 | GND |

ICM-426xx 使用地址 `0x68`、400 kHz I²C。驱动识别 ICM-42605（`WHO_AM_I=0x42`）和 ICM-42688-P（`0x47`）；当前实机检测为 ICM-42605。SDA/SCL 需要一组上拉到 3.3 V 的电阻，模块没有板载上拉时各接 4.7～10 kΩ。SDM20 使用 460800 baud、8N1、无流控，TX/RX 必须交叉连接；模块 1、5 脚悬空。

## 软件数据流

`LinuxIcm426xxSensor` 每帧从 `ACCEL_DATA_X1` 连读加速度和角速度。`Icm426xxMotionFilter` 将安装坐标转换到相机坐标，用角速度预测重力方向，再用加速度缓慢消除漂移。输出重力进入弹道积分，横滚和俯仰进入主界面水平仪。没有磁力计约束的 yaw 只作为相对读数，不参与关键计算。

`LinuxSdm20DistanceSensor` 持续排空串口，但只有主界面按确认后才发布下一帧有效距离。距离显示在主界面顶部，并用于在预测轨迹上插值得到落点准星。数值 `20000 mm` 按照模块协议视为未测到目标。

## 设备树与构建

[`pico-sensors.dts`](pico-sensors.dts) 启用 `I2C3_M1` 和 `UART3_M1`。板端 Linux 5.10 已验证可通过 configfs 动态创建这两个控制器，启动脚本会在应用启动前加载 `/etc/autoaimer/pico-sensors.dtbo`，不需要改写 boot 分区、重编内核或重新烧录整卡镜像。

实体传感器使用独立开关 `AUTOAIMER_SENSOR_HARDWARE`。SC3336 板端构建默认随 `AUTOAIMER_BOARD=ON` 启用，也可以显式指定：

```sh
cmake -S . -B build-sc3336 -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-rv1103.cmake \
  -DLUCKFOX_SDK_PATH="$HOME/luckyfox-rv1103-pico/luckfox-pico" \
  -DAUTOAIMER_BOARD=ON -DAUTOAIMER_SPI_DISPLAY=ON \
  -DAUTOAIMER_SENSOR_HARDWARE=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build-sc3336 --target autoaimer autoaimer_sensor_probe -j2
```

安装时创建 `/etc/autoaimer/sensors-enabled`。启动脚本只有在该标记存在且 `/dev/i2c-3`、`/dev/ttyS3` 均可用时才传入 `--sensors`，缺少设备会明确失败，避免静默使用空传感器。

## 实机检查

重启后先确认：

```sh
test -c /dev/i2c-3
test -c /dev/ttyS3
/tmp/autoaimer_sensor_probe
```

探针应报告 ICM-42605 或 ICM-42688-P，输出有限的重力和倾角，并在 SDM20 对准 0.05～20 m 内目标时输出距离。当前实机安装为模块 `+Y` 向画面右、`-X` 向画面下、`+Z` 向镜头前方；设备水平时相机坐标重力应接近 `{0,+9.81,0}`。若以后改变模块安装方向，只调整 `icm42688.cpp` 中集中的轴映射。

ICM-42605 在关闭 I3C SDR/DDR 时可能在写事务末尾返回 NACK，即使寄存器已经生效。Linux 驱动只在该接口配置步骤中做有限读回核验，不会影响每帧采样。2026-11-20 实机连续运行 5 次探针、两次服务启停和一次冷启动均成功；最终服务同时持有 `/dev/i2c-3` 与 `/dev/ttyS3`。
