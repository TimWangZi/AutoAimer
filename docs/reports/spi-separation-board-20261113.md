# SPI 分层版本上板帧率记录

> 这是 20261113 对应版本的历史验证记录。文中原始日志、画布和二进制路径位于本地 `test-results/spi-separation-board-20261113/`，不包含在源码仓库中。

2026-11-13，通过 Windows ADB 在标准 Luckfox Pico（RV1103，Linux 5.10.160）验证无摄像头版本。新版已安装到 `/usr/bin/autoaimer` 并保持运行，启动参数为 `--spi-hz 40000000`，两个线程。

## 实测结果

每轮预热 3 秒，再测量约 30 秒，分成三个约 10 秒区间。帧率由 `spi0.0/statistics/bytes_tx` 增量除以每帧 93,770 字节及单调时钟采样时长计算；统计的是送屏吞吐率，不是合成线程产帧速度或面板扫描频率。

| 版本 | 平均 FPS | 每帧毫秒 | 三个区间 FPS | 进程 CPU |
|---|---:|---:|---|---:|
| 旧版（前） | 29.5744 | 33.8131 | 29.6226 / 29.5664 / 29.5341 | 97.45% |
| 新版 | 29.6042 | 33.7790 | 29.6232 / 29.6248 / 29.5644 | 97.49% |
| 旧版（后） | 29.6115 | 33.7706 | 29.6162 / 29.6001 / 29.6184 | 97.44% |

前后旧版均值 **29.5930 FPS**，新版变化 **+0.0378%**。差异落在本轮区间波动内，可视为持平，没有测出明显性能损失，也不能将微小正差异视为有效提速。

三个测量进程均为两个线程、退出码 0。SPI 错误及超时增量全部为 0。CPU governor 保持 `ondemand`，全部采样频率为 [1104000] kHz；没有调整 CPU 策略或 SPI 时钟配置。双方均使用双缓冲、30 个裁剪条带，每帧 180 次 SPI 写入、93,770 字节。

## 安装和画布校验

候选程序先在 `/tmp/autoaimer-spi-separated` 运行对照，通过后执行 12 帧有限运行并保存画布。板上保存的 PPM 与 Ubuntu 对应输出 SHA-256 一致，程序正常退出。随后原子替换正式程序并通过原启动脚本启动，确认唯一进程、两个线程、运行文件校验值正确，安装过程 SPI 错误和超时增量均为 0。
