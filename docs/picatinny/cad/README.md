# 皮卡汀尼导轨参考几何（MIL-STD-1913，公制）

按 MIL-STD-1913 Figure 1 / Figure 2 的尺寸换算成 mm 生成的 2D 几何，
单位统一为 **mm**，原点在导轨**底面中心**，X 沿导轨长度，Y 宽度，Z 高度。

## 剖面（自上而下）

```
        .748 ±.002   顶面      19.00      ← 基准 A，零件坐在这上面
        .835 -.005   脊线      21.20      ← 顶部 45° 倒角斜出去的位置，顶面下 1.10
        .108         燕尾面     2.77      ← 45° 收回，夹具真正的承力面
        .617 -.010   底面      15.67
        .367 MIN     总高       9.32
```

两条 45° 面方向相反：上面那条从 19.00 **向外下**斜到 21.20 脊线（让位 / 导入），
下面那条从 21.20 **向内下**收到 15.67（倒扣，夹爪从这里压下去）。
脊线是一道 90° 尖棱，在 z = 8.22。

## 文件

| 文件 | 内容 |
|---|---|
| `rail_profile_1913.dxf` | 导轨名义剖面（8 顶点闭合多边形），拉伸即得 3D |
| `rail_cavity_0.05.dxf` | 你的零件要挖掉的空腔：45° 面和侧面单边 0.05，底面让 0.50 |
| `rail_side_200mm.dxf` | 200 mm 侧视：19 个槽，槽宽 5.23，槽距 10.01，槽深 3.00 |
| `preview.png` | 上面几个 DXF 的预览 |
| `gen_picatinny.py` | 生成器，改参数后重跑 |

## 关键尺寸

```
顶面 19.00（.748±.002）   脊线 21.20（.835−.005，顶面下 1.10）
底面 15.67（.617−.010）   总高 9.32（.367 MIN）
顶部倒角 45°×1.10         燕尾 45°×2.77（.108）
槽宽 5.23 +0.20           槽距 10.01          槽深 3.00 +0.20
顶面平面度 0.13           内角 R1.5 max
```

## 怎么用

1. CAD 里 `插入 → DXF`，导入 `rail_profile_1913.dxf`；
2. 拉伸所需长度得到导轨实体；需要带槽的版本照 `rail_side_200mm.dxf` 切槽；
3. 设计自己的零件时，把 `rail_cavity_0.05.dxf` 当作被挖掉的轮廓：
   顶面贴合（基准 A），45° 面留 0.05，靠横栓把夹爪压下去。

## 注意

- 脊线是尖棱，夹爪的内角必须躲开它（留 0.2 以上），否则会顶在棱上夹不紧；
- 承力的是脊线**以下**那条 2.77 高的燕尾面，夹爪唇边至少要伸到脊线以下 1.5~2.0；
- 这是标准的名义几何，真实导轨顶面最多小 0.13、槽最多大 0.20，夹紧结构要留可调行程；
- DXF 为 R12（AC1009），图层：`PROFILE` / `CAVITY` / `CENTER` / `DATUM` / `NOTE`。
